## 2026-03-05 - Overlay Focus Management & ARIA Synchronization
**Learning:** Programmatic manipulation of overlay displays (e.g. `style.display = 'flex'`) bypasses established toggle functions (`window.toggleChat()`), leading to desynchronized ARIA states (`aria-expanded`) and lost focus management for screen readers and keyboard users. Additionally, nested informative images inside `aria-label` buttons create redundant and confusing screen reader announcements.
**Action:** Always centralize visibility toggles into a single function that manages both display state and accessibility attributes (`aria-expanded`, focus traps). For icon-only launcher buttons with an `aria-label`, explicitly hide the nested `<img>` or `<svg>` using `aria-hidden="true"` and an empty `alt=""` attribute to ensure a clean, single announcement.
